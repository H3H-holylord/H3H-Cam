H3H Cam 4.0.11 — полный Portable для Windows x64

1. Распакуйте ВЕСЬ архив в отдельную папку. Не запускайте EXE из окна ZIP.
2. Запустите H3HCam Receiver.exe. Устанавливать .NET, FFmpeg или ADB не нужно.
3. Установите H3H-Cam-4.0.5.apk на Android-телефон и разрешите доступ к камере.
   APK можно перенести на телефон и открыть там. Для установки по кабелю:
   включите на телефоне параметры разработчика → Отладка по USB,
   подключите кабель для данных, разблокируйте телефон и запустите
   «Установить на телефон.cmd». Подтвердите разрешение отладки на телефоне.
4. В клиенте выберите «USB · через ADB», нажмите НАЙТИ, затем СТАРТ.
   Параметры камеры выбираются на компьютере. Пути к инструментам оставьте пустыми.

2560×1440 / 2K: обновите APK, нажмите НАЙТИ и выберите разрешение на компьютере.
Если телефон отдаёт больший размер, подпись «GPU из …» обозначает уменьшение
на GPU телефона. Доступные FPS зависят от камеры и прошивки; начните с 30.
Подробнее: docs/QHD-4.0.11.md.

Для OBS, Discord, Zoom и других приложений включите «Виртуальная камера».
Выберите имя камеры из статуса H3H Cam: «H3H Cam» либо «OBS Virtual Camera».
В OBS добавьте источник «Устройство захвата видео» и выберите эту камеру.
При первом включении перезапустите приложение-потребитель, если камеры нет в списке.
Полная OBS для видеозвонков не требуется. Не запускайте её виртуальную камеру
одновременно с виртуальной камерой H3H Cam.

Wi-Fi: телефон и компьютер должны быть в одной домашней сети. Компьютер может
быть подключён к роутеру по Ethernet. Для первой настройки удобно подключить
телефон по USB, подтвердить отладку, выбрать Wi-Fi и нажать НАЙТИ.
Подробности: docs/QUICKSTART.md.

USB Direct — другой режим без отладки. Он требует поддержки Android Accessory
и драйвера WinUSB. Для первого запуска выберите USB через ADB.
Если Windows не видит телефон даже при подтверждённой отладке, может понадобиться
USB-драйвер производителя телефона. Архив не устанавливает такие драйверы.

В архиве: Windows-клиент со встроенным .NET, FFmpeg, FFplay, ADB с DLL,
libusb, модули виртуальной камеры x64/x86, APK и модель для AI-эффектов.
Папки tools и models сохраняйте рядом с EXE. Все компоненты находятся локально;
при первом запуске клиент не скачивает FFmpeg, ADB или AI-модель.
60 FPS и разрешения зависят от камеры телефона; тяжёлые эффекты увеличивают нагрузку.

Spout2 для OBS — дополнительный способ вывода; для него нужен отдельный плагин.
OBS Studio, программы видеозвонков и драйверы устройств устанавливаются отдельно.
Настройки и логи клиента хранятся в %LOCALAPPDATA%\H3HCam.

Если возникла проблема: Collect-Diagnostics.ps1, docs/QUICKSTART.md,
https://github.com/H3H-holylord/H3H-Cam/issues
Безопасный запуск: H3HCam Receiver.exe --safe-mode
