# Быстрый старт

## Windows

Распакуйте ZIP, запустите H3HCam Receiver.exe. .NET отдельно не нужен.

Установите [FFmpeg/FFplay](https://ffmpeg.org/download.html), а для USB через ADB и Wi-Fi — [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools). Положите программы и их DLL рядом с клиентом или в tools; можно указать пути в интерфейсе. [OBS Studio](https://obsproject.com/) устанавливается отдельно.

## Телефон и USB

Установите APK, откройте приложение и разрешите камеру. Включите параметры разработчика и отладку по USB. Подключите кабель для данных, подтвердите RSA-запрос телефона. В Windows выберите USB, НАЙТИ, доступную камеру и режим, затем СТАРТ. adb reverse выполняется автоматически.

USB Direct/AOA — отдельный режим без отладки Android. Нужны поддержка accessory и WinUSB-драйвер; это не универсальное UVC-устройство. Для первого теста рекомендуется ADB USB.

## Wi-Fi

Телефон и PC должны быть в одной доверенной LAN. Первую настройку удобно выполнить с подключённым USB: клиент включает adb tcpip и определяет IP. Укажите IP телефона и сетевой интерфейс PC в той же сети. Ethernet компьютера совместим с Wi-Fi телефона через общий роутер.

## OBS и видеозвонки

Установите совместимый [Spout2-плагин OBS](https://github.com/Off-World-Live/obs-spout2-plugin/releases), добавьте Spout2 Capture и выберите H3HCam.

Для видеозвонков включите «Виртуальная камера» и запустите поток. Начиная с Windows 4.0.10 её модули включены в ZIP, регистрация выполняется автоматически для текущего пользователя. Полная OBS для этого не требуется. Если приложение видеозвонков уже открыто, обновите его список камер или перезапустите приложение. Выберите имя из статуса клиента: H3H Cam либо OBS Virtual Camera при использовании уже установленной OBS-камеры. При ошибке используйте «Установить / восстановить камеру», доступную и в простом режиме. Не запускайте одновременно конкурирующий выход виртуальной камеры OBS. [Установка и проверка](VIRTUAL-CAMERA-4.0.10.md).

## Задержка в игре

Следите за FPS Direct/Spout и числом пропущенных устаревших кадров. Отключите ненужный предпросмотр и тяжёлые эффекты. Лимит FPS игры может освободить ресурсы GPU. Повышенный приоритет клиента действует автоматически.

При сообщении о баге укажите версии Windows/APK, модель телефона, Android, транспорт, разрешение/FPS и симптомы. Очищайте личные IP, пути и серийные номера перед публикацией логов.
