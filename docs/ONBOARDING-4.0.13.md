# Первый запуск: Windows 4.0.13 и Android 4.0.7

Обновите обе части приложения. Распакуйте Portable целиком, установите APK из него на телефон, откройте H3H Cam и разрешите камеру.

## Wi-Fi через QR, без отладки USB

1. Подключите телефон и ПК к одной локальной сети. ПК может использовать Ethernet.
2. В Windows нажмите **Wi-Fi: показать QR-код**.
3. На телефоне нажмите **СКАНИРОВАТЬ QR (WI-FI)**, наведите камеру на код и подтвердите **СТАРТ**.
4. Windows получит каталог камер, выберет совместимые параметры и подготовит приём. Настройки телефона вручную выравнивать не нужно.

Код действует пять минут. После остановки покажите новый QR для нового подключения. Если компьютер недоступен, проверьте выбранный сетевой адрес, разрешение приложения в брандмауэре и отсутствие изоляции клиентов/гостевой сети на роутере. QR не переключает сетевые адаптеры и не меняет маршруты Windows.

Изменять камеру, качество, фокус и другие доступные параметры нужно в Windows. Экран телефона можно выключить кнопкой питания. Автоматическое выключение экрана с ПК требует ADB; QR не предоставляет этот доступ.

СТОП и закрытие клиента отправляют команду остановки телефону. Если компьютер пропал, Android прекращает поток после 30 секунд без ответов. Управление и статистика проходят по каналу, который открывает телефон; видеопакеты продолжают идти по RTP/UDP с прежней низкой задержкой.

## USB

Для обычного USB-подключения нужен кабель с передачей данных, драйвер производителя, включённая отладка USB и подтверждённый ключ компьютера. В простом режиме нажмите **Подключить и запустить**. Поиск не переключает работающий ADB-телефон в Accessory.

При `unauthorized` разблокируйте телефон и подтвердите запрос. При пустом списке проверьте кабель, порт, отладку и драйвер; зарядка сама по себе не подтверждает передачу данных. USB Direct остаётся дополнительным режимом для устройств с Android Accessory и WinUSB.

## Интерфейс

До обнаружения телефона показаны шаги подключения. После обнаружения появляются камеры и настройки качества. **16:9 Горизонт** — обычная веб-камера; **9:16 Shorts** — вертикальное видео. Кнопка **Помощь** содержит инструкции USB, Wi-Fi и OBS. Существующие настройки и выбранный язык сохраняются.

## Проверки

Windows: `dotnet run --project tests/S8Cam.Tests.csproj -c Release -- unit <folder>` и `-- pairing <folder>`.

Android: `gradlew.bat -p android testDebugUnitTest assembleRelease`. При `-PtestRelease=true` используйте `testReleaseUnitTest` и `assembleReleaseAndroidTest`.

`WifiPairingTest` проверяет чтение реального PNG Windows-кода на Android, обратный канал и запуск/остановку реального потока с компьютером, у которого путь к ADB недоступен. Тест живого потока требует подключённого тестового ПК и подготовленного файла `live-qr.txt`.

Публично распространяйте только APK/Portable и инструкции. Файлы проверок могут содержать локальные сетевые адреса и временные коды подключения.
