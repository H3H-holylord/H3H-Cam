# Быстрый старт

## Windows

Скачайте [полный Portable 4.0.11](https://github.com/H3H-holylord/H3H-Cam/releases/download/v4.0.11/H3H-Cam-4.0.11-Portable.zip), распакуйте **весь** архив в отдельную папку и запустите `H3HCam Receiver.exe`. Не запускайте EXE прямо из окна ZIP. .NET, FFmpeg, FFplay, ADB, модули виртуальной камеры и AI-модель уже включены. Пути к инструментам оставьте пустыми — клиент использует папку `tools` рядом с собой.

[OBS Studio](https://obsproject.com/) устанавливается отдельно.

## Телефон и USB

Установите `H3H-Cam-4.0.5.apk` из Portable на телефон, откройте приложение и разрешите камеру. Для нового GPU-режима QHD обновите и Windows-клиент, и APK. APK можно передать на телефон и открыть там, разрешив установку из выбранного источника. Для установки с PC включите на телефоне параметры разработчика и отладку по USB, подключите кабель для данных и запустите `Установить на телефон.cmd`. Подтвердите RSA-запрос телефона; установщик работает, когда подключён ровно один разрешённый телефон, и обновляет приложение без удаления данных.

В Windows выберите **USB · через ADB**, нажмите **НАЙТИ**, выберите доступную камеру и режим, затем **СТАРТ**. `adb reverse` выполняется автоматически. При `unauthorized` разблокируйте телефон и подтвердите доступ. Если список устройств пуст, проверьте кабель/отладку; при отсутствии драйвера Android в Windows установите USB-драйвер производителя телефона.

USB Direct/AOA — отдельный режим без отладки Android. Нужны поддержка accessory и WinUSB-драйвер; это не универсальное UVC-устройство. Для первого теста рекомендуется ADB USB.

## 2560×1440 / 2K

После обновления нажмите **НАЙТИ**, выберите камеру и **2560 × 1440** в разрешениях. Если захват идёт из большего размера, в списке будет подпись «GPU из …». Выберите доступные FPS; начните с 30. Каталог зависит от Camera2 и кодека: если прошивка не даёт ни 1440p, ни подходящего большего режима, пункт не добавляется. [Как работает QHD](QHD-4.0.11.md).

## Wi-Fi

Телефон и PC должны быть в одной доверенной LAN. Первую настройку удобно выполнить с подключённым USB: клиент включает adb tcpip и определяет IP. Укажите IP телефона и сетевой интерфейс PC в той же сети. Ethernet компьютера совместим с Wi-Fi телефона через общий роутер.

## OBS и видеозвонки

Для простого подключения к OBS включите в H3H Cam «Виртуальная камера», запустите поток и добавьте в OBS источник **Устройство захвата видео**. Выберите имя камеры из статуса клиента: **H3H Cam** либо **OBS Virtual Camera**. Отдельный плагин для этого способа не требуется.

Spout2 — дополнительный способ вывода в OBS. Для него установите совместимый [Spout2-плагин OBS](https://github.com/Off-World-Live/obs-spout2-plugin/releases), включите Spout2 в H3H Cam, добавьте Spout2 Capture и выберите H3HCam.

Для видеозвонков включите «Виртуальная камера» и запустите поток. Начиная с Windows 4.0.10 её модули включены в ZIP, регистрация выполняется автоматически для текущего пользователя. Полная OBS для этого не требуется. Если приложение видеозвонков уже открыто, обновите его список камер или перезапустите приложение. Выберите имя из статуса клиента: H3H Cam либо OBS Virtual Camera при использовании уже установленной OBS-камеры. При ошибке используйте «Установить / восстановить камеру», доступную и в простом режиме. Не запускайте одновременно конкурирующий выход виртуальной камеры OBS. [Установка и проверка](VIRTUAL-CAMERA-4.0.10.md).

## Задержка в игре

Следите за FPS Direct/Spout и числом пропущенных устаревших кадров. Отключите ненужный предпросмотр и тяжёлые эффекты. Лимит FPS игры может освободить ресурсы GPU. Повышенный приоритет клиента действует автоматически.

При сообщении о баге укажите версии Windows/APK, модель телефона, Android, транспорт, разрешение/FPS и симптомы. Очищайте личные IP, пути и серийные номера перед публикацией логов.
