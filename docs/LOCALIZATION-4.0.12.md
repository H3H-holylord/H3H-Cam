# Русский / English — H3H Cam 4.0.12

Windows 4.0.12 и Android 4.0.6 добавляют выбор **Автоматически / Русский / English** в верхней части интерфейса. При автоматическом выборе русский используется для русской системной локали, английский — для остальных. Настройки ПК и телефона независимы и сохраняются между запусками.

## Что переведено

Windows: простой режим, все вкладки Pro, подсказки, основные сообщения и ошибки, окно предпросмотра, HUD, меню в трее и названия камер для отображения. Android: главный экран, поиск ПК по Wi-Fi, разрешения, состояние потока, статистика и уведомление foreground service. Английская инструкция и установщик APK входят в Portable: `README-English.txt`, `README.en.md`, `docs/QUICKSTART.en.md`, `Install-on-phone.cmd`.

Системные сообщения Android/Windows, сообщения производителей камер и необработанные диагностические строки сторонних утилит могут оставаться на исходном языке. Уже записанные логи не переводятся задним числом. Перевод UI не меняет числовой формат RTP/управляющего протокола или идентификаторы камер.

## Реализация

Windows хранит `Language` в обычном AppData JSON. `windows/L.cs` загружает встроенные `windows/Localization/ru.json` и `en.json`. DynamicResource обновляет XAML, а обновление вычисляемых названий не меняет выбранные элементы. Пользовательский текст, имена пресетов и пути не переводятся. Язык не входит в условия перезапуска потока.

Android хранит язык отдельно от `StreamSettings` в SharedPreferences `s8cam_ui`. Строки — в `values/strings.xml` и `values-ru/strings.xml`. После выбора пересоздаётся только Activity; сохранённые флаги команды не позволяют повторно запускать камеру из старого Intent. Действие `UI_LANGUAGE_CHANGED` обновляет существующее уведомление сервиса до входа в код настройки камеры/транспорта. Отложенный ответ Wi-Fi не открывает диалог уничтоженной Activity; сокет поиска закрывается и при таймауте.

## Проверка

- Проверено совпадение 629 ключей Windows RU/EN, параметров форматирования, отсутствие русских строк в английском словаре и наличие всех используемых ключей.
- Тест WPF переключает RU → EN → Auto → EN, проверяет сохранение языка, неизменность 2560×1440 / 30 FPS / 32 Mbps и введённого имени пресета; отображает простой режим и все вкладки Pro.
- На Samsung Note9 / Android 10 инструментальный тест переключает RU/EN в настоящей Activity, проверяет ресурсы и неизменность настроек захвата. Для UI-теста телефон должен быть включён и разблокирован.
- В 20-секундном потоке 1080p60 / 32 Mbps по USB переключены EN → RU → Auto на ПК и в уведомлении Android. Экземпляр foreground service сохранился, полученный MPEG-TS успешно декодирован, проверены устойчивые 60 FPS. Это проверка переключения языка на одном устройстве, не измерение полной задержки камеры.
- Общие unit tests Windows и Android, lint и проверки конечного Portable выполняются перед выпуском.

## Запуск тестов

```powershell
$env:H3HCAM_DATA_DIR = "$PWD\test-results\language-profile"
dotnet run --project tests -c Release -- language-ui test-results/language-ui --safe-mode
dotnet run --project tests -c Release -- stream usb test-results/language-stream YOUR_SERIAL 20 auto continuous 1080p 60fps 32mbps language-toggle
```

Аппаратный тест требует свободного телефона, разрешения камеры и режима 1080p60; после проверки уведомления возвращает язык телефона в Auto. Он сохраняет и восстанавливает настройки захвата. Для Android UI-теста соберите и установите подписанные release и release AndroidTest (`-PtestRelease=true`), затем запустите класс `com.h3h.s8cam.UiLanguageTest` через `am instrument`. Тестовый APK и локальные результаты не входят в Portable.
